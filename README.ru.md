# Telegram Chat Anonymizer

**Русский** | [English](README.md)

[![Tests](https://github.com/Frendyq/telegram-chat-anonymizer/actions/workflows/tests.yml/badge.svg)](https://github.com/Frendyq/telegram-chat-anonymizer/actions/workflows/tests.yml)
[![Release](https://img.shields.io/github/v/release/Frendyq/telegram-chat-anonymizer)](https://github.com/Frendyq/telegram-chat-anonymizer/releases/latest)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Скрипт обезличивает экспорт переписки из Telegram Desktop (`result.json`). Из чата пропадают имена, телефоны, почты, пароли, адреса и другие личные данные. После этого переписку можно отдать на анализ нейросети, исследователю или коллеге.

Скрипт работает **полностью офлайн**: ничего не отправляет в интернет и не требует установки библиотек. Нужен только Python.

---

## Что получится

Было:
```
Мария Иванова: Привет, Алексей Петрович! Мой номер +7 (700) 123-45-67,
               почта maria@example.com, живу на ул. Ленина 15, кв 42
```
Стало:
```
Человек А: Привет, [Человек Б]! Мой номер [ТЕЛЕФОН_1],
           почта [ПОЧТА_1], живу на [АДРЕС_1]
```

Одинаковые значения получают одинаковые метки. Поэтому видно, что `[ИМЯ_3]` в разных сообщениях — один и тот же человек, и переписка остаётся понятной.

## Что скрывается

| Что | Пример | Метка |
|---|---|---|
| Авторы сообщений | Мария Иванова | `Человек А` / `Человек Б` |
| Имена в тексте: падежи, уменьшительные, со строчной буквы, латиницей, растянутые | Ерлану, Лёха, айгерим, Ерлааан | `[ИМЯ_n]` |
| Фамилии и отчества рядом с именем, казахские ФИО | Алексей Петрович, Серікұлы Нұрлан | `[ИМЯ_n]` |
| Телефоны в любом формате | +7 (700) 123-45-67, 87001234567 | `[ТЕЛЕФОН_n]` |
| Почты | name@example.com | `[ПОЧТА_n]` |
| Номера карт (с проверкой по алгоритму Луна), ИИН, длинные номера | 4111 1111 1111 1111 | `[КАРТА_n]`, `[ИИН_n]`, `[НОМЕР_n]` |
| Ссылки, домены, @юзернеймы, t.me/… | t.me/channel, @nickname | `[ССЫЛКА_n]`, `[ДОМЕН_n]`, `[НИК_n]` |
| Пароли, токены, API-ключи | пароль: Summer2024!, sk-…, DB_PASSWORD=… | `[ПАРОЛЬ_n]`, `[СЕКРЕТ_n]` |
| Адреса | ул. Ленина 15, кв 42; мкр Восток-5, д. 8 | `[АДРЕС_n]` |
| Документы и госномера | паспорт N12345678; 777ABC02 | `[ДОКУМЕНТ_n]`, `[ГОСНОМЕР_n]` |
| Координаты, пути `C:\Users\имя` | 43.2389, 76.8897 | `[КООРДИНАТЫ_n]`, `[НИК_n]` |
| Ваши слова из `hide.txt`: город, вуз, работа | Караганда, Каспий банк | `[СКРЫТО_n]` |

Кроме того, из файла удаляются id пользователей, юзернеймы, названия файлов, реакции и служебные события. Пересланные сообщения остаются, а источник пересылки заменяется на `[ЧЕЛОВЕК_n]`. В файле остаются только сообщения двух участников переписки.

Встроенный словарь (`builtin_names.txt`) — это около 1 300 имён:
- русские и украинские;
- казахские;
- узбекские, кыргызские, таджикские;
- татарские и кавказские;
- английские;
- иностранные в русском написании.

## Быстрый старт

### 1. Выгрузите чат из Telegram

1. Откройте **Telegram Desktop** (в приложении для телефона экспорта нет).
2. Откройте нужный чат и нажмите **⋮ → Экспорт истории чата** (*Export chat history*).
3. Снимите все галочки с фото, видео и файлов: нужен только текст.
4. Внизу выберите формат **Машиночитаемый JSON**.
5. Нажмите **Экспортировать**. Получится папка `ChatExport_…` с файлом `result.json`.

### 2а. Windows: готовая программа, Python не нужен

1. Скачайте **`TelegramAnonymizer.exe`** со страницы [Releases](https://github.com/Frendyq/telegram-chat-anonymizer/releases/latest).
2. Запустите программу и выберите `result.json`. Или просто перетащите на программу `result.json` либо всю папку `ChatExport_…`.
3. Программа обезличит чат и сразу проверит результат на утечки.

> Windows может показать предупреждение «Система Windows защитила ваш компьютер»: у программы нет платной цифровой подписи. Нажмите **Подробнее → Выполнить в любом случае**. Программа работает офлайн, а её исходный код открыт в этом репозитории. Если не доверяете готовому `.exe`, соберите его сами: `build_exe.bat`.

Свои списки (`names.txt`, `hide.txt`, `keep.txt`, см. ниже) кладите **рядом с `TelegramAnonymizer.exe`**.

### 2б. Любая система: скрипт на Python

1. Установите Python 3.9 или новее с [python.org](https://www.python.org/downloads/). На Windows при установке отметьте галочку **Add Python to PATH**.
2. Скачайте скрипт: на этой странице **Code → Download ZIP**, или через git:
   ```bash
   git clone https://github.com/Frendyq/telegram-chat-anonymizer.git
   ```
3. Запустите. На Windows проще всего перетащить `result.json` на `run.bat`. Из терминала:
   ```bash
   python anonymize_tg.py "путь\к\result.json" --txt anon.txt --suggest suggest.txt
   ```

Рядом с `result.json` появится `result_anon.json` — обезличенный чат.

## Как добиться хорошего результата

Скрипт находит телефоны, почты, карты и пароли по формату почти без ошибок. **С именами сложнее:** редкое имя, которого нет в словаре, он может не узнать. Поэтому лучше пройти такой цикл.

**1. Впишите известные имена.** Скопируйте `names.example.txt` в `names.txt` и перечислите людей, которые упоминаются в чате: друзей, родственников, коллег, их прозвища и фамилии.
```
Алексей, Лёша, Лёха, Смирнов
Айгерим, Айка
```
Одна строка — один человек, варианты через запятую. Падежи, строчные буквы и латиницу писать не нужно, скрипт добавит их сам.

**2. Скройте места.** Скопируйте `hide.example.txt` в `hide.txt` и впишите город, улицу, вуз, место работы: всё, по чему вас можно узнать.

**3. Запустите с отчётом `--suggest`.** В `suggest.txt` попадут слова с заглавной буквы, которые остались в тексте не в начале предложения. Просмотрите список и допишите найденные имена в `names.txt`.

**4. Если скрипт скрыл лишнее** (например, голосового помощника «Алиса» скрипт считает именем), впишите это слово в `keep.txt`.

**5. Запустите ещё раз и проверьте результат:**
```bash
python check_anon.py "путь\к\result_anon.json"
```
Проверка независимыми правилами ищет остатки телефонов, почт, карт, ссылок, паролей, адресов, документов и имён из `names.txt`. **Она печатает только количество находок, без текста переписки.** Если везде `OK`, файл чистый. С флагом `--show` она покажет сами найденные слова, но тоже без окружающего текста.

> ⚠️ `names.txt`, `hide.txt` и `keep.txt` содержат ваши личные данные. Не публикуйте их. В `.gitignore` они уже исключены.

## Параметры

```
python anonymize_tg.py result.json [параметры]

  -o, --output ФАЙЛ      куда сохранить JSON (по умолчанию result_anon.json рядом)
  --txt ФАЙЛ             сохранить переписку ещё и простым текстом
  --suggest ФАЙЛ         список слов, похожих на пропущенные имена
  --names / --hide / --keep ФАЙЛ
                         свои списки (по умолчанию names.txt / hide.txt / keep.txt рядом со скриптом)
  --a, --b ИМЯ           кого считать «Человеком А» и «Человеком Б»
                         (по умолчанию — два самых активных участника)
  --label-a, --label-b   свои подписи вместо «Человек А» / «Человек Б»
  --no-dates             убрать даты сообщений
  --audit ФАЙЛ           таблица «исходное значение → метка» для проверки.
                         Внимание: в ней все исходные данные, не передавайте её никому
  --no-ner               не использовать natasha, даже если она установлена
```

**Необязательно:** если установить [natasha](https://github.com/natasha/natasha) (`pip install natasha`), скрипт дополнительно будет искать русские имена нейросетевой моделью. Это медленнее, но ловит редкие имена.

## Формат результата

Структура похожа на экспорт Telegram, поэтому файл читают те же инструменты:
```json
{
 "name": "Анонимный чат",
 "participants": ["Человек А", "Человек Б"],
 "messages": [
  {"id": 1, "type": "message", "date": "2026-01-10T09:01:00",
   "from": "Человек А", "from_id": "A", "text": "Привет, [Человек Б]! …"},
  {"id": 2, "from": "Человек Б", "reply_to_message_id": 1, "forwarded": true,
   "forwarded_from": "[ЧЕЛОВЕК_1]", "media": "фото", "text": "…"}
 ]
}
```

## Ограничения

- **Редкое имя, которого нет ни в словаре, ни в `names.txt`**, если его всегда пишут со строчной буквы, не найдётся. Если его пишут с заглавной, оно попадёт в `suggest.txt`.
- **Имена, совпадающие с обычными словами** («Роза», «Вера», «Лев», «мина», «марка»), намеренно не скрываются или скрываются только с заглавной буквы. Если в вашем чате это имена, впишите их в `names.txt`.
- **Пароль из одного словарного слова без подсказки** (просто «qwerty» отдельным сообщением) отличить от обычного слова невозможно.
- **Косвенные детали** (события, профессия, учёба, внешность) скрипт не трогает. По ним знакомые могут узнать человека. Если это важно, вычитайте результат и допишите слова в `hide.txt`.
- **Обрабатывается только экспорт одного чата в формате JSON.** Формат HTML и полный экспорт аккаунта не поддерживаются.

## Тесты и выпуск версий

```bash
python -m unittest discover -s tests
```

Тесты автоматически запускаются на GitHub при каждом изменении: Windows, Linux и macOS, Python 3.9–3.14.

Чтобы выпустить новую версию программы, достаточно поставить тег:
```bash
git tag v1.1.0
git push origin v1.1.0
```
GitHub сам соберёт `TelegramAnonymizer.exe`, проверит его на примере чата и опубликует в [Releases](https://github.com/Frendyq/telegram-chat-anonymizer/releases).
